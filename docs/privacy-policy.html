Who this is for

Playtest Tracker is a dashboard for a game developer. Testers play the developer's game and may send gameplay events and problem reports.

What we collect

  • Developer account: email address, a name you choose, and a password (stored hashed by our authentication provider).
  • Tester data (sent by the game): a random install ID (not a name or email), the game build, gameplay events, session times, device model and Android version, and any text the tester types into a problem report.

Testers are asked not to include personal details. A developer can redact or delete any report.

How it is used

Only to let the developer investigate problems in their own game. We do not sell data, show ads or track you across apps.

Where it is stored

In a Supabase (PostgreSQL) database. Each developer can only read data belonging to their own games.

Retention and deletion

Data is kept while the developer keeps the game in the tracker. Deleting a report removes it. Deleting an account removes the account and everything under its games. See the account deletion page.
